# P2.05 report: the left panel's view is a store request

**Status:** done (orchestrator).

## What changed
- **One way to open a view.** Every site calls `openLeftPanelView(view)`, which is `canvasUIStore.openLeftPanelView`. It stores `leftPanelViewRequest = { view, nonce }`.
  - The nonce makes every call a new request, so asking for Universes again after the user moved to another view still switches back.
  - This replaces three older mechanisms: `leftPanelRef.current.setActiveView(...)` behind a 100 ms `setTimeout` (a no-op if the panel wasn't mounted yet), the `leftPanelInitialView` prop, and its `null`-then-`requestAnimationFrame` re-set.
- **Sites converted (NodeCanvas):**
  - `openUniversesPanel`
  - the welcome-seen onboarding path
  - the three browser-storage auto-connect / "use browser storage" paths
  - the window-event listeners: `redstring:open-federation` / `openGitFederation` (one handler) and `redstring:open-external-link`
  - the pending OAuth / GitHub App return
  - the wizard ask (`'ai'`)
- **Removed:** the `leftPanelInitialView` state, `leftPanelRef` and `ref={leftPanelRef}`, the `initialViewActive` prop (and its comparator key and JSDoc), and `setActiveView` from Panel's imperative handle. `openNodeTab` stays.
- **Panel** subscribes to `leftPanelViewRequest` (left side only) and switches on each new request. On mount it starts at the last requested view, as the old prop did.
- NodeCanvas.jsx: 18,396 → **18,362**; budget lowered.
