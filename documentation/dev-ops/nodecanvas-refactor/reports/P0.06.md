## What changed
- **`npm run test:ci`** (`scripts/check-known-failures.mjs`) runs vitest and compares the result against `test/known-failures.json`. That list holds 67 tests plus 1 file that fails to load, seeded 2026-09-23. The gate fails on:
  - any failure not on the list
  - any list entry that no longer fails (`--prune` trims those)
  - unhandled errors
  - a run that writes no report
- **`npm run lint:undef`** (`scripts/check-undefined-names.mjs`) runs ESLint with only `no-undef` over `src/`, excluding tests. It compares per file and name against `test/known-undefined-names.json` (52 uses across 24 entries). It fails on:
  - a new undefined name, or more uses of one than the baseline allows
  - a baseline entry that has been fixed
  - a newly unparseable file
  - This automates the no-undef compare the orchestrator used to run by hand before each Lane A merge.
- **Why not `npm run lint`:** it reports 4,879 errors today (prop-types 2,480, unused vars 1,318, no-undef 701, mostly Node globals in server files). It can't gate yet.
- **`.github/workflows/ci.yml`** runs `lint:undef`, then `test:ci`, then `build`.
  - The build uses `NODE_OPTIONS=--max-old-space-size=4096`, which `release.yml` already sets. On Node 20's default heap, `vite build` runs out of memory.
- **`verify-staged-bundle.test.js`:** the `plutil` cases run on macOS only. `plutil` doesn't exist on Linux.
- **Tests:** `test/meta/known-failures-gate.test.js` and `test/meta/undefined-names-gate.test.js` cover the comparison logic and keep both lists well formed.
- **X-07:**
  - `isPaused` removed from `useCanvasKeyboard`.
  - `isPausedRef` removed from `useGamepad`.
  - `useNodeDrag` loses its two `pinchSmoothingRef.animationId` cancels (nothing sets that id any more) and the `pinchSmoothingRef` param.
  - NodeCanvas still passes `pinchSmoothingRef` to `useNodeDrag`. That's harmless, and it's Lane A's line to drop.
