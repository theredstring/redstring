## What changed
- **Dependency:** `@playwright/test` added as a devDependency (D-12). `npm run test:canvas` runs `playwright test`.
- **`playwright.config.js`:**
  - Runs its own Vite dev server on port **4873** (override with `CANVAS_E2E_PORT`), with `reuseExistingServer: false`, so it never attaches to Grant's server on 4001.
  - 3 workers and **0 retries**: a flow that needs a retry is flaky, and we want to see that.
  - Viewport 1280×800.
- **`test/e2e/canvas/vite.e2e.config.js`:**
  - Uses the app's `vite.config.js`, with a **worktree-local `cacheDir`**. This fixes the F-68 hazard of writing into the main checkout's `.vite` cache.
- **`global-setup.js`:**
  - Warms the dev server by loading each committed fixture once.
  - A dependency-optimisation reload therefore can't land in the middle of a gesture.
- **`helpers.js`:**
  - Fixture open, store access and camera helpers.
  - Geometry helpers that convert world coordinates to client coordinates.
