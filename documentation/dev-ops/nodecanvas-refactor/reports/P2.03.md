  - The pie's exit callback writes all of these. It runs from an `animationend` handler, and sometimes during PieMenu's own render, which rules out `flushSync`.

- **The control panel's latches**, `lastSelectedNodePrototypes` and `lastSingleSelectedInstanceId` (follow-up commit). Effects set them in the same flush as the pie target. Left in `useState`, that flush rendered twice; `--explain S6` showed the split.

## Bugs fixed
- **B-08:** Panel took `nodeDefinitionIndices` as a prop that its memo comparator ignored. It now reads the store, and NodeCanvas no longer passes it (−2 lines).
- **B-11 (new):** `PanelContentWrapper` read `nodeDefinitionIndices` from **graphStore, which has no such field**. So a node's Components list in the right panel always showed its first definition, whichever one was chosen. It reads the store now.
- **F17 (new flow):** gives Alpha two definitions, only the second with a Beta in it, and switches between them. It fails without the fix and passes with it.
