### Deferred to Playwright (P0.03)

These appear only during an interaction, or cannot be produced faithfully in jsdom.

- **Hover-only rendering:** hover glow; endpoint dots on a *hovered* (unselected) edge; self-loop hover dots, which carry no `data-endpoint-dot` and which the drag doesn't query. The dot elements are the same ones selection renders, so their attributes are covered. The hover *trigger* is not.
- **The dragged node in the `draggingNodeToRender` branch**, and the drop re-query of `[data-instance-id]` after that branch unmounts (useNodeDrag.js:2399-2407). This is F1.
- **Mid-drag re-cache:** `priorLabelState`/`labelTouched` carry-over (useNodeDrag.js:557-560, 591, 610), and the sprite → `<text>` stand-down when a drag starts with truncation on (RCE 1582-1617). This is F1, with labels on.
- **Group drag lift:** `isGroupDragging` transform/scale, and the per-frame group rect and label writes landing correctly (F11).
- **Real baked sprites.** jsdom renders stand-in bitmaps. The attribute contract is covered; the bake pipeline is not.
- **Whether the per-frame geometry writes are correct.** jsdom can't lay anything out. This test only proves the elements exist to be written.
- **Written, not read:** `el.dataset.groupBaseTransform` and `el.style.transition` are written *and* read by the hook itself, so they aren't a render contract.

## Culling-ON variant

It is feasible, and needed no extra stubbing. Why it works (`runCulling`, NodeCanvas.jsx:4312-4610):

- **The key must be absent at import time.** `ENABLE_CULLING` (NC 749-755) reads `localStorage.redstring_disable_culling` once. The culling file clears the key in `vi.hoisted`. Vitest gives each file a fresh module graph and jsdom, so the smoke and contract files setting it doesn't leak.
- **Viewport:** `getAppViewportSize()` (`utils/appViewport.js`) measures `#root`. jsdom's render container has no `#root`, so this falls back to `window.innerWidth × innerHeight` = 1024 × 768. `getBoundingClientRect` is not involved.
- **Camera:** the view-restore layout effect (NC 9790-9845) reads `graphViews.get(activeGraphId)` and calls `transform.jumpTo`. The fixture pins `{ panOffset, zoomLevel: 0.5 }` so the viewport spans world x −124..1924, y −118..1418. The inner padding is `500 / zoom` = 1000 units. Every fixture node is inside that except `far`.
- **Timing:** the first `runCulling` is rAF-scheduled from the reactive effect (NC 4801-4805) and runs a full prune. The harness's hand-driven rAF flush runs it after the layout effect has set the camera.
- **Controls, so neither file can pass vacuously:**
  - With culling on, `far` is absent and exactly 10 nodes mount.
  - With culling off, `far` is present.

  If a hoisted flag ever stops taking effect, one of these fails.

## New findings

- **NEW-1 (bug, VERIFIED code, INFERRED visual): a self-loop's arrowhead shrinks for the whole node drag.**
  - The render draws it with `transform="translate(…) rotate(…) scale(${cw})"` (SLE 154), where `cw = connectionWidth = (textSettings.connectionWidth ?? 1) * CONNECTION_WIDTH_BASE_SCALE (1.25)`.
  - The drag's self-loop branch rewrites that transform **without the scale** (useNodeDrag.js:1015). The regular-arrow path keeps it (`scale(${dragConnWidth})`, useNodeDrag.js:1229).
  - Effect: at default settings the arrowhead drops to 80% for the duration of the drag, then snaps back on drop.
  - Fix: append `scale(${dragConnWidth})` at 1015, in its own `fix(canvas): B-…` commit. This is a Lane C edit to useNodeDrag.js.
  - Worth a 5-second manual check to confirm it's visible.
- **NEW-2 (contract asymmetry, informational): self-loops sit outside most of the contract.**
  - `SelfLoopEdge`'s hit `<path>` has no `data-edge-hit`, and its labels have no `data-connection-label` or `data-label-frame`.
  - The drag's self-loop branch compensates by writing every `path` and every `text` in the wrapper, and the drop restore (useNodeDrag.js:2309-2346) skips self-loops entirely.
  - This works today because the self-loop's drag-written values are a pure function of node position that match the render's. It will break the first time self-loop labels get truncation or sprites.
  - The P3 edge layer should give both renderers one contract. The contract test pins today's shape for self-loops (arrow, `path`, `text`), so that change will show up as a deliberate test edit.
- **NEW-3 (harness): culling can be exercised in jsdom by pinning `graphViews`,** with no `getBoundingClientRect` stub. See the culling section. This is useful for P0.04 and Lane A's `renderBudget` test.
