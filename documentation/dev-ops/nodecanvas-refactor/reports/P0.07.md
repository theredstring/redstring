## Deviations

- **The ratchet is strict: `budget` must equal the line count.** The task specified `lines <= budget` and `lines >= floor`. It also required a failure message saying "when the file shrinks, lower the budget in the same commit". That message only has somewhere to live if shrinking without lowering fails. Without this test, the budget stays at 19,255 while the file shrinks, and regrowth back up to 19,255 passes silently, which is exactly F-49. The strictness is one `it` block. To relax it, delete that block, or change it to `lines >= budget - SLACK`.
