**Status:** done (orchestrator). **Commits:** a whitespace-only collapse of repeated blank lines in NodeCanvas.jsx (16,415 → 16,320), then P2.03b.

## What changed
- **`selectedGroupId`** is in canvasUIStore (the field existed since P2.01). `selectedGroup` is derived: `graphsMap.get(activeGraphId).groups.get(selectedGroupId)`.
- **`setSelectedGroup` keeps its contract:** a group, null, or an updater given the current group. It stores only the id, so the ~90 call sites and the touch and control-panel hooks are unchanged. The color-picker updater that patched the snapshot's color is now a no-op, because the derived group already has the new color.
- **`lastSelectedGroup`** (the exit-animation latch) stays a snapshot, since it must show a group that was just deleted. It's held in a ref updated during render and cleared when the exit animation completes; an effect-set latch after the store write would cost a second render (P2.03). `canvasUIStore.lastSelectedGroupId` stays unused.
- **B-14 (fixed):** the group control panel showed the group as it was when selected; renaming or recoloring it elsewhere (store, undo, collaborator) left the panel stale. F27 fails on the old code.
