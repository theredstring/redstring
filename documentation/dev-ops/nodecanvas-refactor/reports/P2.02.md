# P2.02 report: `selectedInstanceIds` lives in `canvasUIStore`

**Status:** done (orchestrator). The first wired slice of the P2.01 store, so P2.01 now counts as done too.

## What changed
- **NodeCanvas:** `selectedInstanceIds` and `setSelectedInstanceIds` are now bound to `useCanvasUIStore` under the same names.
  - All 29 call sites and every hook that receives them are unchanged, updater calls included: the store setter takes a value or an updater.
- **Mirror refs:**
  - NodeCanvas's `selectedInstanceIdsRef` is now a read-through to `getState()`; its three readers keep the same interface.
  - `useCanvasTouch`'s own mirror is gone; its tap timer reads the store.
  - These values now update when selection is set, not after the next commit. All three readers are fine with that: the focus-on-select effect, the gamepad's panel-mode sync, and the touch tap timer, for which it's more correct.
- **`src/hooks/useNodeActions.js` deleted.** It had no importers (P2.01 NEW-1).
- **Test harness:** `installCanvasStubs` resets the UI store, which outlives a test's canvas.
- NodeCanvas.jsx: 18,412 lines, unchanged.

## Not changed yet
- The wizard's `rs-select-node` listener writes selection (store, sync) and the pie target (still `useState`). That's one extra commit until P2.03 moves the pie target (P2.01 §4).
- The hooks still take selection as parameters. Dropping those parameters is optional clean-up.
