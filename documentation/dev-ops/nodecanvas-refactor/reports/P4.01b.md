# P4.01 (part b) report: `clientToCanvas`, `edgeHitTest`, `canvasHitTest`

**Status:** done (orchestrator), apart from the touch-constant reconciliation, which still waits on Q5 (F-44). Branch `refactor/p4.01b`.

## What changed
1. **`viewportMath.clientToCanvas(clientX, clientY, rect, pan, zoom, canvas)`** (d27e21b) replaces **17** inline client-to-canvas conversions in NodeCanvas: the 15 `const rawX = …; const rawY = …;` pairs and 2 object literals.
   - The arithmetic is the inline copies' own, in the same order, so results are bit-identical.
   - A missing canvas counts as offset 0. Four copies already guarded that way; the other 13 would have thrown.
2. **`src/utils/canvas/edgeHitTest.js`** (02aea89):
   - `findNearestEdgeAtCanvasPoint` (about 200 lines) moved verbatim, with its explanatory comments. It takes NodeCanvas's render-time values as a `scene` object; NodeCanvas keeps a `useCallback` wrapper with the same dependency list.
   - `edgeHitThreshold(pointerKind, isRoutedStyle, connectionWidth, zoom)` is the pure part of `getEdgeHitThreshold`.
   - `EDGE_HIT_FLOOR_PX_*`, `EDGE_HIT_TOUCH_BOOST` and `EDGE_HOVER_STICKY_FRACTION` moved with them.
3. **`src/utils/canvas/canvasHitTest.js`** (b9d2fea): `selectionInRect` (the marquee's selection), `groupTitleAtCanvasPoint` and `groupDragOffsets`, all moved verbatim. The NodeCanvas wrappers read the container rect and the refs at call time, as before.
   - Not moved: `findConnectionDropTarget` and `isInsideNode`. They are thin loops over `GeometryUtils.isInsideNode` that need the container rect, so they belong with the gesture controller (P4.04).
