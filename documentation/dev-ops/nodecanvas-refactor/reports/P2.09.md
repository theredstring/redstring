## Where Panel's renders came from
Measured before any change, with a Profiler inside Panel's memo. A Profiler around `<Panel>` in NodeCanvas reports on every NodeCanvas render even when the memo bails out, so it overcounts.

| Scenario | Left Panel | Right Panel |
|---|---|---|
| S1 drag-pan | 2 | 0 |
| S4 node drag | 6 | 2 |
| S5 marquee | 18 | 0 |
| S7 select | 2 | 0 |

- **Selection and `hydratedNodes` props** (left): the comparator compared them, so every selection change re-rendered the whole left Panel. Only Semantic Discovery used them.
- **Panel's own subscriptions to the whole `graphs` and `edges` Maps** (both sides): a drop re-rendered both panels and recomputed every left view's derived lists, in both panels.
- **F-76 (new):** LeftAIView, which stays mounted while hidden, polled `getFileStatus()` every 3 s into state that nothing read. That's the S1 pair, and one or two commits in any scenario longer than 3 s.

## What changed
- **`src/components/canvas/hosts/PanelHost.jsx`**: `<Profiler id="LeftPanel"|"RightPanel">` around `<Panel>`. It takes only `side` and passes store values, the store's toggle actions, a mount-time actions snapshot (as NodeCanvas's `storeActions` was), and `runCanvasCommand('startHurtleFromPanel', …)`.
- **Panel:**
  - Plain `memo`; the custom comparator is gone, so callbacks aren't ignored any more.
  - `forwardRef`, `useImperativeHandle` and `openNodeTab` are gone (X-05: nothing read the ref).
  - No `graphs` or `edges` subscription. The right header colour reads one narrow selector (the active web's defining node id).
  - Deleted as dead: `graphsForGrid`, `activeGraphNodes`, and a `console.log` that dumped every type group on each prototype change.
- **Views subscribe for themselves:**
  - **LeftGridView** (Open Webs) derives `openGraphsForList`. Its previews need positions, so it follows node moves, but only while that tab is open. The Open Webs search looks up open graphs at click time.
  - **LeftAIView** takes the active web as value selectors (exists, name, chip colour, node and edge counts, graph count). Its send, agent, new-conversation and manual-tool handlers read the store when they run.
  - **LeftSemanticDiscoveryView** reads the one selected instance from canvasUIStore and its prototype from graphStore.
- **NodeCanvas:** `<PanelHost side="left" />` and `<PanelHost side="right" />`; registers `startHurtleFromPanel`; `panelRef` removed.
- NodeCanvas.jsx: 17,994 → **17,968**; budget lowered.
