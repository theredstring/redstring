## What changed
- **The box is imperative.**
  - `beginMarquee` / `updateMarquee` / `endMarquee` hold the box in `marqueeBoxRef` and write it straight to the `<rect>` through a callback ref.
  - `selectionRect` state is gone. `selectionStart` stays state only so the `<rect>` mounts and unmounts with the gesture.
- **The selection** is re-derived with `selectionFromRect` at most once per rAF. `setSelectedInstanceIds` runs only when membership changes.
- **B-02:** the `canvasWorker.calculateSelection` round trip is gone from both the live box and the release, so a late worker reply can't bring back a rectangle.
- **The gamepad marquee** (`marqueeControlRef`) shares the same begin/update/end path.
- **B-01 (separate commit):** the release runs the same `selectionFromRect` pass, which skips node-group anchors. F4's B-01 flow is now a normal test.
- **Regression found and fixed:**
  - The marquee branch of `handleMouseMove` returned before `mouseMoved` was ever set. Mouseup uses that flag to swallow the box's trailing click, so the click deselected everything the box had just selected.
  - Before P1.04 the flag was set only by accident: the anchor was React state, one render behind, so the first moves fell through to the generic threshold check.
  - Playwright F4 and F11 caught it. The jsdom render-budget test didn't, because jsdom fires no trailing click.
  - Fix: the branch sets `mouseMoved` itself.
